# Stronkie's Hunters v1.5

- Every New York place now has its own boss: Harlem (blob), Manhattan (skyscraper), Harbor (kraken), JFK (plane), Statue of Liberty (crowned statue).
- Each boss has its own attack list (homing / spread / sniper / pincer) and attack speed; Statue of Liberty is the nastiest.
- Source cleaned up: dead data removed (old home tune, unused strings), new header with memory map, theme/boss code moved to RAM under BASIC.

Tested on a real Commodore 64 and working. Built and regression-tested in a custom 6502 emulator.
