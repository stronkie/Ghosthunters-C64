# Stronkie's Zappers v1.11

The game was renamed from "Ghost Hunters" to **Ghost Zappers** (the old name is a copyrighted one).

- New logo: GHOST ZAPPERS.
- Title screen, Hall of Fame heading and credits now say "Zappers" and "Ghost Zapper".
- Files are now called `stronkies_zappers.prg`, `.d64` and `.asm`.
- Includes the white ghost in the logo from v1.10.1.

Gameplay is unchanged. Built and regression-tested in a custom 6502 emulator. Not yet confirmed on a real C64.
